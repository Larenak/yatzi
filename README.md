# Ятзи

Быстрая браузерная дуэль в классический Ятзи, подготовленная как статический проект для Яндекс Игр. Игрок соревнуется с виртуальным соперником со случайным ником; у каждого своя таблица из 13 категорий. Белые кубики анимированно приземляются в неподвижные чёрные лотки, финальный бросок соперника задерживается для чтения, а при выборе счёта кости перелетают в нужную ячейку с плавным начислением очков.

## Локальный запуск

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Проверка логики

```powershell
npm test
```

## Публикация в Яндекс Играх

Поместите в ZIP-архив файлы `index.html`, `styles.css`, `app.js` и `game.js`. `index.html` должен находиться в корне архива. Игра подключает SDK динамически: на хостинге Яндекса используется `/sdk.js`, на собственном домене — официальный абсолютный адрес SDK.

Реализованы адаптивные мобильный и компьютерный интерфейсы, `LoadingAPI.ready()`, разметка геймплея, события паузы/возобновления и автоопределение русского/английского языка через SDK.
