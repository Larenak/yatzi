# Ятзи

Быстрая браузерная дуэль в классический Ятзи, подготовленная как статический проект для Яндекс Игр. Игрок соревнуется с виртуальным соперником со случайным ником; у каждого своя таблица из 13 категорий. Белые кубики анимированно приземляются в неподвижные чёрные лотки, финальный бросок соперника задерживается для чтения, а при выборе счёта кости перелетают в нужную ячейку с плавным начислением очков.

В игре есть кошелёк монет и магазин. За полный просмотр rewarded video начисляется 10 монет, за победу — 25 монет. После трёх бесплатных бросков игрок может сделать ещё до трёх платных бросков в том же ходу — каждый стоит 50 монет. После нажатия «ПОНЯТНО — ИГРАТЬ!» запускается обязательная реклама с наградой, а после каждого 10-го завершённого хода такой же ролик запускается автоматически. Баланс и счётчик ходов сохраняются в облачных данных игрока Яндекс Игр и дублируются в локальном хранилище.

Покупки используют расходуемые товары `coins_50`, `coins_200`, `coins_500` и `coins_1000`. Игра получает каталог, цены и значок портальной валюты через SDK, восстанавливает необработанные покупки при запуске и консумирует их только после сохранения начисления. Готовый CSV для Консоли разработчика находится в `yandex-purchases.csv`.

## Локальный запуск

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`.
